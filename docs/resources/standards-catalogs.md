# Standards, tooling & resource catalogs

The formats, metadata schemas and registries that make everything above interoperable — and the catalogs to use when this list runs out.

*9 resources. Generated from [`data/neuroscience_data_resources.csv`](../about/contributing.md) — edit the CSV, not this page.*

| Resource | Host (Region) | Species | Data type / technique | Level | Access | What it is |
|---|---|---|---|---|---|---|
| **[Neurodata Without Borders (NWB)](https://nwb.org)** | NWB community / Kavli Foundation, LBNL, CatalystNeuro (USA) | All | Standardized HDF5-based format for cellular neurophysiology + behavior | Cells; activity; behavior | Open source, BSD | The data standard that makes DANDI possible; PyNWB/MatNWB plus conversion tools (NeuroConv) read most acquisition-system formats. |
| **[Brain Imaging Data Structure (BIDS)](https://bids.neuroimaging.io)** | BIDS community / INCF-endorsed (International) | Human; animal (BEP032) | Directory and metadata standard for MRI, EEG, MEG, iEEG, PET, microscopy, motion | Activity; behavior | Open, CC-BY | The organizing standard behind OpenNeuro and most modern neuroimaging pipelines, with validators and a growing set of modality extensions. |
| **[DataLad](https://www.datalad.org)** | Forschungszentrum Jülich / Dartmouth (Germany; USA) | All | Decentralized dataset version control built on Git/git-annex | All | Open source, MIT | Lets you install, track and share multi-terabyte datasets by reference; the backbone of several national data portals. |
| **[openMINDS & EBRAINS Knowledge Graph](https://openminds-documentation.readthedocs.io)** | EBRAINS AISBL / INCF (Europe) | All | Metadata schemas and FAIR knowledge graph for neuroscience | All | Open, MIT | Provides the metadata vocabulary that makes EBRAINS datasets machine-findable and cross-linkable. |
| **[INCF Training Space & standards portal](https://www.incf.org)** | International Neuroinformatics Coordinating Facility (International) | All | Endorsed standards, best practices and open training materials | All | Fully open | Maintains the community process by which neuroscience standards (BIDS, NWB, NIX, openMINDS) are reviewed and endorsed, plus free courses. |
| **[NITRC](https://www.nitrc.org)** | Neuroimaging Informatics Tools and Resources Clearinghouse (NIH) (USA) | Human; animal | Tool registry, image repository (NITRC-IR) and cloud compute environment | All | Fully open | Long-standing catalog of neuroimaging software and datasets, including many atlases distributed nowhere else. |
| **[dkNET & SciCrunch resource registry](https://scicrunch.org/resources)** | UC San Diego / NIDDK (USA) | All | Research resource identifiers (RRIDs) for antibodies, lines, tools, databases | All | Fully open | Resolves what a resource is and whether it is still maintained — the authoritative source for RRIDs cited in methods sections. |
| **[re3data](https://www.re3data.org)** | DataCite / Karlsruhe Institute of Technology, HU Berlin (Germany) | All | Global registry of research data repositories with filters by discipline and access policy | All | Fully open, CC-BY | Use it to discover domain repositories beyond this list and to check licensing and persistence policies before depositing. |
| **[Zenodo, Figshare, Dryad & OSF](https://zenodo.org)** | CERN; Digital Science; Dryad; Center for Open Science (International) | All | General-purpose DOI-minting repositories used for one-off neuroscience datasets | All | Fully open | Where many individual-paper datasets live when no domain archive fits; searchable but weakly standardized, so metadata quality varies. |
